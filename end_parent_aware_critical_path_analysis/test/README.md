# Testing end parent aware critcal path analysis

In this directory are some traces from our evaluation of CPA2. These can be used to try out CPA2; the expected output traces can be found in the expected directory.

Note that only the required flags (i.e., input and output files) were specified when generating the expected files except for fig-12-async-end-parent-removed, where --find_end_parents was also used to infer end parents.
